Chặn nối lệnhBash(ls*) không match ls; rm -rf ~: có ; & | ` < > $( hoặc xuống dòng là không match.

Không có Glob/GrepCLI hiện tại không có hai tool này; tìm kiếm đi qua Bash.

Trạng thái conversation

Field status trong bảng conversations. Dashboard tô màu theo trạng thái này.

stateDiagram-v2
  [*] --> idle
  idle --> running: run_turn / message tới
  running --> awaiting_approval: tool cần duyệt
  awaiting_approval --> running: approve / deny / timeout
  running --> idle: ResultMessage OK
  running --> error: lỗi / turn timeout 600s
  running --> interrupted: Stop / Take over
  interrupted --> awaiting_owner: inbound đang chờ
  idle --> awaiting_owner: mode = manual khi message tới
  awaiting_owner --> idle: owner reply / hand back / timeout 900s
  idle --> running: hand back → agent chạy tiếp
Directioninbound (peer mở), outbound (agent mình mở), local (owner chạy riêng hoặc fork).
Modeauto: agent trả lời. manual: owner trả lời tay.

Owner controls

Mọi nút trên dashboard là một REST call; kết quả quay về qua WebSocket.

sequenceDiagram
  participant O as Owner (dashboard)
  participant API as /api
  participant S as SessionManager
  participant W as SessionWorker
  participant P as Peer đang chờ
  O->>API: POST /takeover
  API->>S: mode = manual
  S->>W: interrupt()
  Note over S,P: Inbound đang chạy → _wait_for_owner
  alt Owner trả lời tay
    O->>API: POST /reply {text}
    API->>S: manual_reply → resolve gate
    S-->>P: text của owner
  else Trả lại cho agent
    O->>API: POST /handback
    API->>S: mode = auto → resolve gate
    S->>W: run_turn("Continue where you left off…")
    W-->>P: câu trả lời của agent
  end
NútEndpointHiệu ứng
Inject/injectĐang chạy: chèn vào lượt hiện tại. Rảnh: lượt local, peer không thấy.
Stop/interruptclient.interrupt(), inbound chuyển sang chờ owner.
Take over / Hand back/takeover · /handbackĐổi mode manual ↔ auto.
Reply/replyTrả lời peer bằng tay. 409 nếu không ai chờ.
Fork/forkCopy Claude session thành conversation local mới.
Approve / Deny/api/approvals/{id}Quyết định tool đang chờ.
