Internal Agent Fleet — architecture

Each teammate's Claude Code agents talk to each other over A2A on Agent Mesh. Written notes: docs/NOTES.md; the Office (game-like map) is described there and in CONTEXT.md.

Topology: hub, machines, agents

One hub per team (plus the Office world server). Each machine runs two processes: agentmesh-node (network) and the node server (agents + dashboard).

Each A2A message becomes one turn of the Claude session bound to its contextId.

Tool policy: allow / deny / ask

One source of truth: sessions.policy_decision, called from both the PreToolUse hook and can_use_tool. Contact tools follow the agent's contact policy; an accepted Assignment also allows file edits.

Conversation status

The status field of conversations. The Office shows it as a coloured chip.

stateDiagram-v2
  [*] --> idle
  idle --> running: run_turn / message arrives
  running --> awaiting_approval: tool needs approval
  awaiting_approval --> running: approve / deny / timeout
  running --> idle: ResultMessage OK
  running --> error: failure / turn timeout 600s
  running --> interrupted: Stop / Take over
  interrupted --> awaiting_owner: inbound waiting
  idle --> awaiting_owner: mode = manual when a message arrives
  awaiting_owner --> idle: owner reply / hand back / timeout 900s
  idle --> running: hand back → agent continues
Directioninbound (a peer started it), outbound (my agent started it), local (owner only, or a fork).
Modeauto: the agent answers. manual: the owner answers by hand.

Owner controls

Every control is a REST call; the result comes back over the WebSocket.

  else Hand back to the agent
    O->>API: POST /handback
    API->>S: mode = auto → resolve gate
    S->>W: run_turn("Continue where you left off…")
    W-->>P: agent's answer
  end
ControlEndpointEffect
Inject/injectWhile running: added to the current turn. When idle: a private turn the peer never sees.
Stop/interruptclient.interrupt(); an inbound turn then waits for the owner.
Take over / Hand back/takeover · /handbackSwitch mode manual ↔ auto (inbound only in the Office).
Reply/replyAnswer the peer by hand. 409 when nobody is waiting.
Fork/forkCopy the Claude session into a new private conversation.
Approve / Deny/api/approvals/{id}Decide a waiting tool use or Assignment.

Data and event flow

Every write goes through Store: saved to SQLite, then published on the EventBus → WebSocket → the dashboard's single reducer.

  agents { string id PK "owner/name" string working_dir json allowed_tools json denied_tools bool enabled "soft delete" }
  conversations { string id PK string agent_id FK string context_id "unique with agent_id" string direction string session_id "Claude session" string status string mode int turn_count }
  messages { string id PK string role "peer agent owner tool system" string kind "text tool_use tool_result status file" string content json data }
  approvals { string id PK string tool_name json tool_input string status "pending allowed denied timed_out" }
  files { string id PK string direction "received sent" string path int size }
  audit_log { int id PK string event json detail "metadata only, no body" }
